# Codectechnologies-Internship-VLSI


## Project 1: VLSI Design of FIR Filter for DSP Applications

**What it does**:  
Removes noise from a digital signal. Like a bass/treble filter in music.

**How it works**:  
Takes input signal → Multiplies with 16 filter values → Adds them → Gives clean output signal

**Details**:
- 16-tap Low Pass FIR Filter in Verilog
- Clock: 100MHz, Cutoff: ~1kHz 
- Tested using testbench on EDA Playground

**Tools**: Verilog, EDA Playground

## Project 2: ASIC Design Flow Simulation Using Open-Source Tools

**What it does**:  
Converted RTL code to gate-level circuit. This is how chips are made.

**How it works**:  
RTL Code → Synthesis → Netlist → Ready for chip manufacturing

**Details**:

- Learned ASIC design flow using Cadence tools
